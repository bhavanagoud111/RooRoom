01The problem

1Midnight, stuck. A general chatbot doesn't know this course, and will happily do the graded homework.
30Same question, thirty emails. Professors answer one at a time, days later, in one language.
0Honest feedback never arrives, because nobody wants to be named.
OUR QUESTION

Can a team of small, single-job AI agents make one professor answer reach every student, safely?

02Meet the agents

One job each, its own prompt, the smallest model that does the job, and only the tools it needs.

Buddy Matcher pairs opted-in classmates using the Tutor's study topics and shared free time on the calendar.

03How it works: one shared course memory

What one agent learns, the others use. When the professor publishes an answer, the Tutor cites it from then on, the Translator delivers it in every language, and the Calendar picks up any new date.
